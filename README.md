# Chai & Chapter - Book Cafe Website

Chai & Chapter is a college training project for a digital book cafe website. It combines authentic Indian chai culture with dedicated reading nooks, an artisanal cafe menu, community events, founder background, reader reviews, and a book-club newsletter.

This project is structured based on the reference website pattern (Krish's Handicraft Store) using semantic HTML5, clean CSS3 (Flexbox and Grid), and basic JavaScript.

## Project Structure

1. **Header / Navigation:** Logo, business name, navigation links linking to section IDs, and primary call-to-action button.
2. **Home / Hero Section:** Main heading, tagline, description, hero image, and action buttons.
3. **Main Form (Reserve a Reading Nook):** Input fields for Full Name, Contact, Date, Time Slot, Preferred Nook, Reading Genre, and Special Requests.
4. **Services / How It Works:** 3-step feature cards explaining how patrons browse, reserve, and enjoy the cafe.
5. **Menu / Products Section:** Product cards organized under Signature Chai & Teas, Artisanal Coffees, and Bakes & Savories.
6. **Events Section:** Cards showcasing community gatherings (Shaam-e-Shayari, Author Spotlight, Sunday Book Swap) with RSVP triggers.
7. **About Section:** Two-column section featuring founder story and quote.
8. **Reviews Section:** Customer review cards with star ratings and reader badges.
9. **Newsletter Section:** Email subscription card for The Chapter Club.
10. **Footer:** Contact details, opening hours, quick links, social icons, and copyright.

## Technologies Used

* HTML5 (Semantic elements: header, nav, section, form, footer)
* CSS3 (CSS Flexbox, CSS Grid, Media Queries, Custom Variables)
* JavaScript (Basic DOM manipulation, form event handling, alerts)
* Boxicons & Google Fonts (External styling assets)
* ScrollReveal (Simple scroll animations)
